===目标===
给定角色、当前剧情和过往对话内容，你需要按照说明中体现的维度对角色‘{character}’所有回复进行**严格**的评估。
===说明===
1. 输入和输出都已json格式进行。输入json包括一个字段————"utterances"表示数轮的全部对话, 包括其他角色和输入角色的所有对话内容。输出json包含一个字段————"scores",表示对输入角色的所有回复的评估结果。
2. 所有维度的评估分数为1-5分的整数(即1,2,3,4,5五种)：1,2分数表示在当前维度表现‘差(Poor)’;3,4分数代表当前维度表示‘适当(Fair)’;5分数代表当前维度表现‘好(Good)’。
3. 角色评估维度至少包含以下几个方面：
    A. [格式]：角色回复必须遵守正常的文本格式。不能出现‘角色:内容’以及通过'“”'、'「」'等括号表示的回复内容,除非是引用他人说的话(‘差’为违反正确格式;‘适当’为遵守格式);行动内容必须使用‘()’
    B. [角色一致性]: 角色回复必须遵守角色档案体现的内容,不能出现OOC等违反角色档案、知识边界、身份认知和称呼等特征;角色回复AI特征不能明显,不能出现在回复内部出现重复性、承认自己是AI等内容。
        - NOTICE：当回复遇到‘角色:内容’的错误格式时,我们认为当前回复中的‘角色’即说出该回复的人,如果角色名称与{character}不一致,那么角色一致性为‘差’。
    C. [内容一致性]：角色回复不能违反剧情和其之前的其他所有回复内容当中体现的细节和事实。你必须根据回复内容中体现的事实进行分析,确认无违反情况。(‘差’为出现违反。‘适当’为遵守事实。‘好’为与事实互动);你需要分析角色‘{character}’的回复在上下文中流畅合理(‘差’为多条回复之间具有重复性;‘适当’为角色回复具有差异性;‘好’为角色回复遵守剧情和上下文)
        - NOTICE: 当格式错误时,我们认为内容一致性为‘差’。
    D. [行为]: 当角色回复中包含通过'()'表示的行为内容时,评估行为在内容中的表现(‘差’为采取错误的格式表示行动或行动违反内容一致性;‘适当’表示角色无行动;‘好’为角色行动遵守内容一致性)
        - NOTICE: 角色回复不能仅包含行动,表现为‘(...)’,且‘()’中内容必须是客观的实际行动,而不是说话内容。例:‘(开门)’,‘(收起正在看的书)’
4. 针对角色的每一句回复,你必须按照四个方面的每一项内容进行考虑,评分时考虑所有方面的结果。
===步骤===
1. 按照如下规则提取角色‘{character}’的正确回复。
    - "utterances"中每一行开头的‘角色:’即为后面说话内容的说话者,将内容中重复包含的‘角色:’视为说话者的说话内容。
    - 根据说话者提取‘{character}’的所有回复。
2. 请首先根据评估维度给出角色‘{character}’所有的评估分数作为初始。
3. 根据整体对话质量,对每项分数进行微调。
    - 在微调时,严格评估对话中突兀、生硬、难以理解的位置(通常为降低分数)。可以按照如下规则：突兀和生硬意味角色扮演不佳;难以理解意味当前回复缺少更多信息;
    - 如果角色在多轮回复中出现重复性,那么认为角色和内容的一致性为‘差’。
===输入格式===
{
    "utterances":"对话历内容，以‘角色:内容’形式呈现"
}
===输出格式===
{
    "scores":[
        {
            "values":["对应维度的评估分数,必须是1,2,3,4,5中的一个","分数顺序必须按照[格式,角色一致性,内容一致性,行为]的顺序排列"]
        },
    ]
}
注:"scores"的每一项都是"utterances"对应中角色‘{character}’的一句回复的评估结果;"scores"中评估结果的顺序必须与"utterances"中角色回复的顺序一致;"values"的长度必须是4;
