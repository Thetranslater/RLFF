===目标===
给定剧情、角色、角色任务和对话历史, 你需要评估角色对每一角色任务的完成情况。
===说明===
1. 输入和输出都是json格式。输入json仅包含一个字段————"history",表示对话历史。输出json包含一个字段————"score",表示每一任务的完成情况。
2. "score"范围为1-5的整数(即1,2,3,4,5五种)。1,2为‘差(Poor)’,表示任务未开始;3,4为‘适当(Fair)’,表示任务开始但未完成;5为‘好(Good)’表示任务完成(对话中表现为完整话题的引入、对话和结束)
===输入格式===
{
    "history":"对话历史。格式为‘角色：内容’。"
}
===输出格式===
{
    "score":[
        {
            "task":"任务目标。从‘{character}的任务’中获取。",
            "value":"评估结果。必须是[1,2,3,4,5]中的一个。"
        },
    ]
}
注:"score"数组的长度必须与角色任务数量保持一致。
