===目标===
给定角色、当前剧情和过往对话内容，你需要按照说明中体现的维度对角色‘{character}’所有回复进行**严格**的评估。
===说明===
1. 输入和输出都已json格式进行。输入json包括一个字段————"utterances"表示数轮的全部对话, 包括其他角色和输入角色的所有对话内容。输出json包含一个字段————"scores",表示对输入角色的所有回复的评估结果。
2. 所有维度的评估分数为1-5分的整数(即1,2,3,4,5五种)：1,2分数表示在当前维度表现‘差(Poor)’;3,4分数代表当前维度表示‘适当(Fair)’;5分数代表当前维度表现‘好(Good)’。
3. 角色评估维度包含以下几个方面：
    - [一致性]:评估当前回复是否符合当前角色特性(包含语言风格、身份认知等特性。‘差’表示完全脱离角色,角色身份错误,AI特征明显等;‘适当’表示当前回复不体现角色特性或不确定);评估当前回复是否与给定剧情和之前对话的相关性(‘差’表示完全不相关或极大偏离对话或剧情);评估当前回复的格式是否正确,在回复中不应包含'“”'、'""'或'「」'等格式,除非在引用某人的话,在回复中也不应出现'角色:内容'这样的格式。综合以上要求给出一个评估分数。
    - [流畅]:评估当前回复的情绪在对话历史中是否**合理**(‘差’表示情绪转折突兀或不合理的情绪表达;‘适当’表示情绪模糊或正常对话);评估回复在引出话题时是否流畅合理(‘差’表示引入突兀);评估回复与之前的回复是否具有重复性(‘差’表示具有明显的重复性语句)
    - [知识边界]:评估当前回复是否违反了角色的知识边界(‘差’表示回复中体现的知识或背景违反了角色常识或知识;‘适当’表示当前回复无知识或模糊)。
    - [行为]:评估当前回复中体现的行动内容(使用‘()’表示)在上下文中是否合理(‘差’表示行动违反对话历史或回复本身的内容;‘适当’表示回复中无行动)。
4. 针对角色的每一句回复,你必须按照四个方面的每一项内容进行考虑,评分是时虑所有方面的结果。
===输入格式===
{
    "utterances":"对话历史，以‘角色:内容’形式呈现"
}
===输出格式===
{
    "scores":[
        {
            "values":["对应维度的评估分数,必须是1,2,3,4,5中的一个","分数顺序必须按照[一致性,流畅,知识边界,行为]的顺序排列"]
        },
    ]
}
注:"scores"的每一项都是"utterances"对应中角色‘{character}’的一句回复的评估结果;"scores"中评估结果的顺序必须与"utterances"中角色回复的顺序一致;"values"的长度必须是4;
